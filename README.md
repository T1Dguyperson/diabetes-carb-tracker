# Diabetes Carb Tracker

A simple Android app for Type 1 diabetes nutrition tracking.

Features:
- Search foods by name
- Check barcode input
- Manual food entry by name like pizza
- See carbs, protein, fat, and calories
- Save meal history
- Daily total summary

This project is intended for personal tracking and educational use only.
It is not a medical device and does not replace medical advice.

## Setup
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Choose a device or emulator.
4. Run the app.

## Disclaimer
The app is designed to help with food logging and carb estimation for Type 1 diabetes, but users should always follow their healthcare professional recommendations.
